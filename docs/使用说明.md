# 使用说明

本说明适用于 `D:\并行计算实验\项目\campus-kv-final`，不依赖其他项目目录。

## 启动和停止

在 PowerShell 中执行：

```powershell
cd 'D:\并行计算实验\项目\campus-kv-final'
./scripts/start.ps1
```

如果提示执行策略禁止脚本，可在当前窗口执行 `Set-ExecutionPolicy -Scope Process Bypass` 后重试。也可双击根目录“启动系统.bat”。需要仅检查 Java、运行文件和端口时执行 `./scripts/start.ps1 -Check`。

等待约10秒，访问 <http://127.0.0.1:8081>。系统由三个节点进程和一个Web进程组成。日志在 `logs`，独立节点磁盘及账户数据库在 `data`。首次启动自动创建演示账户。

| 角色 | 用户名 | 密码 |
|---|---|---|
| 管理员 | admin | Admin@12345 |
| 申请人 | student、student2 | Student@12345 |

使用完执行 `./scripts/stop.ps1` 或双击“停止系统.bat”。停止保留数据，下次启动继续恢复。无需管理员身份运行整个应用；若系统无法核对进程归属，先回到启动服务的同一用户窗口操作。

如果提示端口被占用，请在原启动目录停止先前服务，再启动本目录。本目录不会自动停止其他目录服务。启动后长时间无法访问，查看 `logs/web.err`、`logs/web.log` 和节点日志。

## 预约流程

1. 管理员首次登录后点击顶部“管理员初始化场所”，刷新列表。
2. 申请人选择场所和日期，在开放时间内填写预约。申请需满足页面的提前量、人数及日期等约束；待审核申请可以重叠。
3. 管理员进入预约审批，批准第一份申请。只有已批准预约占用时段。
4. 对同一场所、同一天的重叠申请进行批准，系统会提示时间冲突，申请仍保留待审核。区间首尾相接允许共存。
5. 取消会修改本预约状态并释放占用；普通用户受取消截止时间限制，管理员按业务权限操作。

节点页面 <http://127.0.0.1:8081/lab.html> 用于观察节点角色、可达性与应用位置。其本地观察读可以暂时落后；预约页面的核心 GET/SCAN 使用复制日志提交路径。

## 修改源码与构建

需要 JDK 17+、Maven 3.9+。先停止本目录服务，运行：

```powershell
./scripts/stop.ps1
./scripts/build.ps1
./scripts/start.ps1
```

构建会运行测试、编译源文件并把运行依赖放到 `target/lib`。首次通过 Maven 下载依赖需要网络。若本机已有 Maven 和依赖缓存，可显式指定，目录不绑定任何旧工程：

```powershell
./scripts/build.ps1 -MavenCommand 'C:\tools\apache-maven\bin\mvn.cmd' -MavenRepository 'C:\maven-cache' -Offline
```

上述路径是参数示例，请换成本机实际安装路径。运行现成编译文件无需 Maven。`pom.xml` 统一声明 Java 与依赖版本；`target` 是可重新生成的构建目录。

## 备份并恢复空数据

只在需要重新开始时执行 `./scripts/reset-demo.ps1`。脚本停止本目录服务，将 `data` 移到本目录 `data-backups`，随后执行 `./scripts/start.ps1` 建立新数据。它不会复制旧项目数据。

故障实验会创建样例预约、停止节点和模拟链路故障，属于可选实验流程，详见实验说明。普通运行和PPT讲解不需要重跑这些实验。
