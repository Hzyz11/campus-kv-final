# 实验说明

日常使用与课程讲解以四个机制为主。实验工具保留用于核对实现，不是启动系统的必经步骤。

## 原始记录与本次构建

`results/reference-2026-11-20` 原样保留2026年11月20日的12项正式实验、请求历史与24组性能记录。历史记录中的运行目录、节点编号、请求ID属于当时运行，不代表本次重测。本次代码构建测试记录见 `results/build-check`。

## 可选重跑

需要 Node.js 18+。先停止其他目录服务，在本目录备份并清空数据，再启动：

```powershell
./scripts/reset-demo.ps1
./scripts/start.ps1
```

等节点选主和账户初始化完成（通常10秒左右），执行：

```powershell
node scripts/experiments.cjs
```

脚本会生成预约与实验键、终止并重启节点、模拟分区和业务时钟偏移，结果写入 `results/experiments.json`、`results/history.json`、`results/performance.json`。历史归档目录不会被覆盖。迁移实验辅助进程为 `scripts/migration-receiver.cjs`。

本机三进程共享硬件；进程故障且保留磁盘不同于整机或磁盘损坏。24组性能、960请求是已有测量配置，共享日志和串行网关限制吞吐，不能据此宣称已解决热点扩展性。
