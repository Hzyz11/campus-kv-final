## 直接运行

运行需要 JDK 17+ 和 Windows PowerShell。已附编译好的 `target/classes` 和运行依赖 `target/lib`，直接启动无需 Maven 或联网。

双击 **启动系统.bat**，等待约10秒后访问 <http://127.0.0.1:8081>。管理员 `admin / Admin@12345`；申请人 `student`、`student2`，密码 `Student@12345`。首次以管理员登录，点击顶部“管理员初始化场所”，再刷新。

节点观察页面：<http://127.0.0.1:8081/lab.html>。结束时双击 **停止系统.bat**。

启动前先停止其他目录中运行的同一项目。此项目使用8081、19000–19002、19100–19102、19300–19302端口。启动脚本发现端口占用会退出；停止脚本核对进程归属后只处理本目录进程。

## 目录

| 目录或文件 | 用途 |
|---|---|
| `src/main` | 当前正式源码、页面和配置 |
| `src/test` | 业务及 KV 自动化测试 |
| `scripts` | 启动、停止、构建、数据备份重置及可选故障实验 |
| `target/classes`、`target/lib` | 本次从正式源码构建的运行文件及依赖 |
| `docs` | 当前使用、机制、实验说明和最新PPT |
| `results/reference-2026-11-20` | 正式实验的原始记录，日期明确，不作为本次新测量 |
| `results/build-check` | 本次构建测试记录 |
| `data`、`logs` | 运行时自动生成，本次交付不带业务数据 |

修改代码后使用 `./scripts/build.ps1` 重新构建，需要 JDK 与 Maven 3.9+。首次构建可能需要联网下载依赖，详见使用说明。实验脚本另外需要 Node.js 18+。

业务启动入口统一使用 `distributed` 配置。`Api.java`、`CampusService.java` 等数据库模块是当前项目的公共基础和测试依赖，不是另一份旧源码；实际分布式预约入口是 `DistributedApi.java`。完整停用、使用登记和费用流程不属于本次 KV 预约核心。
